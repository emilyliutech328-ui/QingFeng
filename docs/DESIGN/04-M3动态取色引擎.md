# M3（Material You）动态取色引擎重构

> 目标：按 Material Design 3 规范重构应用的色彩体系。
> 参考：M3 官方文档 https://m3.material.io/styles/color/system
> 状态：Phase 1 已实施（2026-11-16）

## 一、为什么不是「全盘换 Theme.Material3」

轻风阅读的底座（legado）有成熟的**自定义主题系统**：用户可选任意主色/强调色/背景，
支持日夜间切换、阅读页独立配色、墨水屏模式。这些全部建立在 `ThemeStore` 的
「取色 → 写 SharedPreferences → 各界面 `ThemeStore.primaryColor(ctx)` 读取」链路上。

直接把主题换成 `Theme.Material3.*` 会：

1. 废掉用户自定义颜色（M3 主题色由系统/种子色决定）
2. 与阅读页的自绘排版引擎冲突（阅读器是 Canvas 自绘，不走 View 主题）
3. 牵连几乎所有自定义 View（这恰是上游的核心资产）

因此采取「**取其引擎、融其 token**」策略：把 M3 最有价值的**动态取色算法**完整引入，
输出对齐现有主题链路；组件与形状层后续渐进对齐。

## 二、M3 色彩系统速览

| 概念 | 内容 |
|---|---|
| **HCT** | Hue-Chroma-Tone 色彩空间（基于 CAM16 颜色感知模型）。Hue 色相、Chroma 彩度、Tone 明度（0~100，即 L*）。感知均匀，是 M3 一切取色的基础 |
| **Tonal Palette** | 一个色相的明度阶梯：tone 0（黑）→ 100（白），共 13 个标准档位（0/10/20/…/90/99/100） |
| **语义 token** | 27 个角色色：primary/onPrimary/primaryContainer/…/surface/surfaceVariant/outline/inverse…，**明暗两套**由同一 palette 不同 tone 档位生成 |
| **种子色（seed）** | 从壁纸/品牌色提炼的单一颜色，量化（QuantizerCelebi）→ 打分（Score）选出 |
| **tone 档位约定** | 浅色主题 primary=tone 40、container=90、background=98；深色主题 primary=80、container=30、background=6。**任何种子色都自动满足对比度** |

## 三、落地架构

```
壁纸/图片/自定义色
      │  降采样 96px
      ▼
QuantizerCelebi.quantize(pixels, 128)     ← WSmeans/Wu 混合量化
      │  Map<色, 计数>
      ▼
Score.score(map)                          ← 官方打分：过滤近黑近白低饱和，
      │  排序候选                              倾向「饱和但不过艳」
      ▼
seed 种子色
      ▼
Hct.fromInt(seed) → TonalPalette          ← CAM16 空间，7 张调色板
      │  (primary/secondary/tertiary/neutral/neutralVariant/error)
      ▼
Scheme.light(seed) / Scheme.dark(seed)    ← 27 token 完整输出
      │
      ├── Monet.apply()：primary/primaryDark(tone30)/tertiary/background
      │   写入 ThemeStore（现有主题链路，全 UI 生效）
      └── Monet.lastScheme：完整 token 缓存，供新界面取 container/outline 等
```

### 代码位置

| 模块 | 位置 | 说明 |
|---|---|---|
| 官方算法（19 类，3375 行 Java） | `app/src/main/java/io/legado/app/lib/theme/m3/` | 来自 material-color-utilities @ `4dbd965df6`（2022-06-10，初版 Material You 规范），Apache-2.0。包名统一为 `io.legado.app.lib.theme.m3`，其余零改动 |
| 引擎入口 | `lib/theme/Monet.kt` | API 不变（`fromWallpaper`/`fromImage`/`fromBitmap`/`apply`/`refresh`），内部换成 M3 流水线；新增 `schemeOf(seed)` / `tone(seed, tone)` / `lastScheme` |
| 行为测试 | `app/src/test/.../M3ColorTest.kt` | 7 项结构性约束：tone 档位范围、明暗差异、色相保留、量化打分、container 层级 |

### token 映射（M3 → 现有主题链路）

| M3 token | 现有链路 | 说明 |
|---|---|---|
| `Scheme.primary` | `ThemeStore.primaryColor` | tone 40/80，对 surface 自动可读 |
| `TonalPalette.of(primary).tone(30)` | `ThemeStore.primaryColorDark` | 状态栏/深色工具栏，沿用旧语义 |
| `Scheme.tertiary` | `ThemeStore.accentColor` | M3 的对比强调色（色相自动偏移），替代旧的「+24° 手工偏移」 |
| `Scheme.background` | `ThemeStore.backgroundColor` | M3 background |
| 其余 23 个 token | `Monet.lastScheme` | 缓存在内存，新界面按需取用 |

## 四、Phase 1 变化清单（已实施）

1. 引入 material-color-utilities 核心算法（19 个类）
2. `Monet.kt` 引擎重写：HSV 简化算法 → M3 官方流水线
3. 强调色改为 M3 tertiary（原来是 hue+24° 手工偏移，色彩关系不如 M3 协调）
4. 状态栏深色档改为 tone 30（原来是 `ColorUtils.darkenColor` 黑白混合）
5. 设置页开关文案更新，注明 Material You / M3
6. 新增 7 项引擎行为测试（`M3ColorTest`）
